## 2. 유형별 대표 답변 패턴

### 비용 구성
- 무제한 수정 + 직접 수정 교육으로 "추가 비용 부담 없음" 강조 (리뷰 1,070)
- "왜 싸요?" → 납품 단가 기준, 많이 만들어서 품질을 올린다 (리뷰 561)

### 호스팅·도메인
- "없어도 됩니다, 선택과 설정을 안내해 드려요" (리뷰 332)
- 1년 무상 호스팅 후 **연 19.8만 원** 연장 — 자체 호스팅에 묶는 판매자도 있음 (리뷰 274)
- 다른 호스팅을 쓰려면 하드코딩이라 더 비싸다 → 자기 솔루션 호스팅 유도 (리뷰 258)
- "호스팅이 뭔가요?"부터 설명하는 곳도 있음 → 고객 수준이 매우 초보

### 수정
- 무제한 수정 (리뷰 1,070) / 매뉴얼로 직접 수정, "650곳이 해냈다" (리뷰 449)
- 오픈 후 3개월 자기 오류 무상, 간단 교체는 남은 횟수 안에서, 기능·페이지 추가는 견적 (리뷰 142)
- 1년간 텍스트·이미지 무료 교체 (리뷰 141)

### 자료 준비
- 로고 · 메뉴 구성 · 메뉴별 문구/사진 · 참고 사이트 1~2개. "기획서 없어도 상담으로 정리" (리뷰 142)
- "자료 없어도 괜찮다, 임시 이미지로 먼저 만들고 교체" (리뷰 69)
- 자료가 많을수록 기간 단축 (리뷰 157)

### 작업 기간
- 패키지별 고정 일수 명시 (5페이지 10일 / 15페이지 15일) 또는 "범위 따라 상담"
- 자료 준비·피드백 속도에 따라 달라진다는 단서는 공통

### 직접 관리
- 게시물·문의내역 관리 기능 제공, 관리자 화면 맞춤 디자인은 추가 비용

### 템플릿 vs 맞춤
- 템플릿: 샘플 골라 7~10일, 저렴 / 맞춤: 기간·비용 더 (리뷰 274 — 템플릿을 장점으로 설명)
- 템플릿 상품도 "추가 비용 = 도메인 연 1만 원 + 호스팅 월 1,500원, 절차 대행" (리뷰 195)
- 반대로 "템플릿 안 씀, 브랜드 맞춤"을 내세우는 곳도 (리뷰 90)

### 유지보수
- "별도 계약으로 가능" (대부분) / 기본 유지보수(도메인 연장·SSL 등) 1년 무료 (리뷰 78)

### SEO
- 기본 SEO·검색엔진 등록 제공 + **"순위·상위 노출은 보장하지 않음"** 명시가 공통

### 소유권
- "소유권은 고객에게", "소스·DB 제공", "다른 개발자에게 이전 가능", "업체에 묶이지 않는 구조" — 소수지만 **신뢰 포인트**로 쓰임

### 환불
- 크몽 기본 규정 그대로가 다수 / 템플릿형은 "7일 내 100% 환불(커스텀 전)" / 맞춤형은 "시안 확정 전까지"

## 3. 우리한테 의미하는 것

- FAQ는 **6~8개**면 충분 (시장 평균 6개). 돈 관련 3개는 무조건 넣기: 추가 비용 · 호스팅/도메인 · 수정.
- **차별화 포인트로 쓸 수 있는 질문:**
  - "호스팅에 묶이나요?" → 경쟁자 일부는 자체 호스팅 연 20만 원 / 우리는 **고객 명의 카페24 월 몇천 원, 언제든 이전 가능**
  - "누구 소유예요?" → 유료 빌더·라이선스 없음, **100% 고객 소유**
  - "직접 고칠 수 있나요?" → 워드프레스 기본 편집기로 글·사진·공지 직접, 영상 매뉴얼
- 고객 수준이 초보 → 용어(호스팅·도메인·SSL)를 한 줄로 풀어 쓰기.
- SEO는 기본 등록만, **순위 보장 안 함**을 명시 (분쟁 예방, 시장 공통).

## 4. 우리 FAQ 초안

> 금액·횟수·기간은 미정 → `service-guide.md` §9 결정 후 채움. `{ }` 표시가 빈칸.

**Q. 템플릿이면 다른 회사랑 똑같은 홈페이지 아닌가요?**
디자이너가 만든 템플릿을 바탕으로 로고·색·문구·사진을 회사에 맞게 바꿔 드립니다. 데모 사이트를 먼저 보고 고르실 수 있어서, 완성 모습을 미리 알고 시작하실 수 있어요.

**Q. 제작비 말고 추가로 드는 비용이 있나요?**
홈페이지를 띄우는 데 필요한 도메인(주소, 연 1~3만 원)과 호스팅(서버, 월 몇천 원)만 고객님이 카페24에 직접 내세요. 유료 프로그램·라이선스 비용이나 매달 내는 유지비는 없습니다.

**Q. 호스팅·도메인이 뭔지 몰라요. 어떻게 준비하나요?**
도메인은 홈페이지 주소, 호스팅은 홈페이지를 올려 두는 공간이에요. 캡처가 들어간 안내서를 드리니 따라 하시면 되고, 연결과 보안 설정(https)은 제가 해 드려요.

**Q. 홈페이지는 누구 소유인가요? 나중에 다른 곳으로 옮길 수 있나요?**
고객님 명의 카페24 계정에 만들어지므로 100% 고객님 소유입니다. 워드프레스 기반이라 나중에 다른 업체나 개발자에게 맡기셔도 그대로 이어서 쓸 수 있어요.

**Q. 완성 후에 제가 직접 고칠 수 있나요?**
네. 관리자 화면에서 글·사진 교체, 페이지 수정, 공지사항 작성을 직접 하실 수 있어요. 사용법 영상 매뉴얼을 함께 드립니다.

**Q. 수정은 몇 번 되나요?**
작업 중 수정은 {N}회 포함이며, 요청은 모아서 한 번에 주시면 1회로 계산해요. 오탈자·문구·사진 교체는 수정, 새 페이지·새 기능·디자인 전체 변경은 추가 작업이에요. 오픈 후 {1개월} 동안 제가 만든 부분의 오류는 무료로 고쳐 드려요.

**Q. 얼마나 걸리나요?**
자료가 모두 도착한 날부터 {N}일이에요. 문구나 사진이 늦어지면 그만큼 늦어질 수 있어요.

**Q. 무엇을 준비해야 하나요? 사진이나 문구가 없어요.**
상호·로고·연락처·주소와 페이지별 문구·사진이 필요해요. 자료 요청 양식을 드리니 채워 주시면 되고, 사진이 없으면 무료 이미지로, 문구가 없으면 키워드만 주시면 초안을 잡아 드려요.

**Q. 네이버·구글에 나오나요?**
네이버·구글에 기본 등록과 검색 설정을 해 드려요. 다만 검색 순위나 상위 노출은 보장하지 않아요.

**Q. 예약·결제·회원가입도 되나요?**
이 상품은 회사·매장 소개용 홈페이지예요. 예약·결제·회원 기능은 포함되지 않으며, 필요하시면 먼저 문의해 주세요.

**Q. 마음에 안 들면 환불되나요?**
크몽 취소·환불 규정을 따라요. 작업 시작 전이면 전액 환불되고, 시작 후에는 진행한 만큼을 뺀 금액이 환불돼요. 카페24에 직접 내신 호스팅·도메인 비용은 환불 대상이 아니에요.
