# SEO · AEO · GEO 조사

> 조사일: 2026-11-02 · 웹 자료 + 크몽 검색 API로 판매자 현황 확인
> 결론부터: **템플릿에 "기본기"를 넣는 건 쉽고 싸다. 하지만 "AI에 뜨게 해 드립니다"는 아무도 보장할 수 없다.**

---

## 1. 쉬운 말로

| 용어 | 뜻 | 비유 |
|---|---|---|
| **SEO** (검색엔진 최적화) | 네이버·구글 **검색 결과 목록**에 잘 나오게 | 도서관 책에 제목·목차·색인을 제대로 붙이기 |
| **AEO** (답변엔진 최적화) | 검색창 맨 위 **"한 줄 답"**·AI 요약에 내 글이 뽑히게 | 질문에 바로 답하는 문장을 써 두기 |
| **GEO** (생성형 AI 최적화) | 챗GPT·제미나이·네이버 AI 브리핑이 **답을 만들 때 내 사이트를 인용**하게 | AI가 참고서로 쓰기 좋은 글 만들기 |

→ 셋은 따로가 아니라 **같은 기본기의 확장**. 사이트 구조·정보가 정확하면 셋 다 유리해진다. AEO/GEO는 새 기술이라기보다 "SEO + 질문에 바로 답하는 글쓰기"에 가깝다.

---

## 2. 한국 검색 현실

| 사실 | 의미 |
|---|---|
| 검색 점유율 **네이버 약 64% · 구글 약 28%** (2026 상반기) | 소상공인 고객에겐 **네이버가 먼저** |
| 네이버 **AI 브리핑**이 인용하는 출처의 **약 82%가 네이버 내부**(블로그·플레이스·지도·쇼핑), 외부 웹은 18% | 홈페이지만으로 AI 브리핑에 뜨긴 어렵다. **스마트플레이스·블로그가 더 큰 영향** |
| 네이버는 AI 브리핑 출처 선정 기준을 **공개하지 않음** | "AI 브리핑 노출 보장"은 근거 없는 약속 |
| 구글 **AI 모드** 한국어 출시 (2025-09) | 구글 쪽 AI 답변도 한국어로 생김 → 구조화된 사이트가 유리 |
| **스마트플레이스**: 무료, 지도·통합검색·플레이스에 노출, 업체명·업종·대표 키워드로 검색 반영 | 매장 업종(학원·뷰티·요식 등)은 **홈페이지보다 플레이스가 먼저 보임** |
| **서치어드바이저**(네이버) · **서치 콘솔**(구글): 사이트 등록 → 소유 확인 → 사이트맵 제출. 등록해도 노출은 심사(약 2주) | 등록은 우리가 해 줄 수 있지만, 노출은 검색엔진이 결정 |

## 3. 무엇이 실제로 효과 있나 (근거 강도별)

| 근거 | 항목 | 우리 판단 |
|---|---|---|
| **강함** | 정확한 정보(상호·주소·전화·영업시간)가 사이트·플레이스·블로그에서 **똑같이** 적혀 있음 | 필수. 템플릿 변수 한곳에서 관리 |
| **강함** | 질문형 제목 + 바로 답하는 첫 문장, 표·목록, 구체적 숫자 (GEO 논문 KDD 2024) | FAQ·서비스 소개 패턴을 이 구조로 |
| **강함** | 다른 곳에서의 언급(블로그 후기·언론·지도 리뷰) | 고객 몫. 사이트로는 못 함 → 안내만 |
| **기본** | title·설명문·제목 순서(H1/H2)·이미지 대체텍스트·사이트맵·robots·https·모바일·속도 | 블록 테마에 기본 내장. 워드프레스가 사이트맵 자동 생성 |
| **엇갈림** | 스키마(구조화 데이터: Organization·LocalBusiness·FAQPage) | 넣되 **실제 있는 정보만**. 효과 과장 금지 |
| **효과 없음** | **llms.txt** (AI용 안내 파일) — 조사에서 대부분 요청조차 안 들어옴, 노출과 상관없음 | 넣지 않음. 넣어도 "효과"로 팔지 않음 |

## 4. 크몽 판매자는 어떻게 파나

검색어별 서비스 수 (크몽 전체, 2026-11-02):

| 검색어 | 서비스 수 | 주로 어느 카테고리 |
|---|---|---|
| AEO | 251 | AI 마케팅 · 전자책 · 블로그 관리 (홈페이지 제작은 40개 중 6개) |
| GEO | 310 | AI 마케팅 · 언론홍보 · 전자책 |
| 네이버 AI 브리핑 | 214 | 블로그 자동화 · 전자책 · AI 마케팅 (홈페이지 제작 0) |

- **AEO/GEO는 홈페이지 제작보다 "마케팅 대행·진단·전자책" 상품으로 팔림.** 1만~3만 원 진단/전자책부터 99만~132만 원 관리 대행까지.
- 홈페이지 제작에서 내건 예: "AI가 찾는 SEO+AEO+GEO 홈페이지"(4만), "SEO·AI 검색 최적화 반응형"(29만·33만), "병원 SEO AEO GEO 홈페이지"(110만), "워드프레스 SEO·AI 검색 최적화"(99만).
- 앞선 조사: 홈페이지 제작 상세페이지의 **48%가 SEO를 언급**, FAQ에선 **"기본 SEO 제공 + 순위 보장 안 함"**이 공통.
- 즉 제목에 "SEO·AI 검색 최적화"를 붙이는 건 **이미 흔한 문구** → 차별점이 아니라 **빠지면 손해인 기본 항목**.

## 5. 우리 템플릿에 기본으로 넣을 것

> 블록 테마 + 워드프레스 기본 기능으로 가능한 것만. 별도 SEO 플러그인은 사용자 확인 후 결정 (CLAUDE.md 플러그인 규칙).

**테마에 내장 (템플릿 만들 때 1번)**
- [ ] 페이지마다 제목 1개(H1) + 순서 맞는 소제목(H2·H3)
- [ ] 모든 이미지 대체텍스트 입력 칸 안내
- [ ] 모바일 반응형 · 이미지 용량 최적화 · 불필요한 스크립트 없음 (속도)
- [ ] FAQ 섹션 패턴: **질문형 제목 + 첫 문장에 바로 답**
- [ ] 서비스·가격 섹션: 표·목록 형태, 숫자 명확히
- [ ] 연락처·주소·영업시간을 **한곳(변수)**에서 관리 → 사이트 전체에 같은 표기
- [ ] 스키마: Organization / LocalBusiness / FAQPage — **고객이 준 실제 정보만**
- [ ] 최종 수정일 표시 (공지·블로그)

**주문마다 (납품 때)**
- [ ] 사이트 제목·설명문 입력
- [ ] 네이버 서치어드바이저 · 구글 서치 콘솔 등록 + 사이트맵 제출
- [ ] https 확인
- [ ] 스마트플레이스 주소·전화와 사이트 표기 일치 확인 (플레이스 등록은 고객이 직접, 안내서 제공)

## 6. 절대 약속하지 않을 것

- 네이버·구글 **상위 노출, 순위**
- 네이버 AI 브리핑 · 챗GPT · 구글 AI 답변 **인용·노출**
- "AEO/GEO 완료" 같은 결과형 표현 → **"AI 검색이 읽기 좋은 구조로 제작"** 정도로만

근거: 검색엔진·AI가 기준을 공개하지 않고, 사이트 밖 요인(플레이스·블로그·리뷰)이 더 크다. 리뷰 분석에서 1점의 주원인이 "약속과 다름"이었음.
