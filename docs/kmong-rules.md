# 크몽 규정 조사 (판매자 입장)

> 조사일: 2026-11-03
> 근거: 크몽 전문가센터 공식 문서 (아래 출처). 블로그 수치가 공식과 다를 때는 공식을 따랐어요.
> 규정은 바뀔 수 있으니 서비스 등록 직전에 한 번 더 확인해야 해요.

---

## 1. 한눈에 — 우리 계획에 영향 주는 것

| 규정 | 우리한테 의미 | 영향 |
|---|---|---|
| **설명·이미지·포트폴리오에 외부 링크·연락처·QR 금지** | 상세페이지에 **데모 사이트 주소를 적을 수 없어요** | **큼** — "데모 먼저 보고 고르기" 방식을 다시 설계해야 함 (§3) |
| 결제 전 외부 연락·직접 결제 금지 (최대 365일 이용 제한) | 상담·결제는 전부 크몽 안에서 해야 해요 | 큼 |
| 경력·전공·수상 같은 표현은 **증빙**을 프로필에 등록해야 함 | "디자이너가 직접 만듦"을 쓰려면 경력 증빙이 필요해요 | 중간 |
| "1위·최고·유일·최초·100% 보장" 금지, 근거 없는 비교·비방 금지 | "호스팅에 묶는 업체 주의" 같은 **역마케팅은 위험** | 중간 |
| "템플릿 작업물 단순 판매"는 비승인될 수 있음 (디자인 카테고리 기준) | **제공 범위와 맞춤 작업 내용**을 분명히 적어야 해요 | 중간 |
| 다른 판매자와 지나치게 비슷한 설명·가격 구성은 비승인 | 경쟁사 문구를 베끼면 안 돼요 | 작음 |
| 수수료 약 21.7% (70만 원 이하) | 가격을 정할 때 실수령은 약 78%로 계산해요 | 중간 |

## 2. 수수료 · 정산

**판매자 수수료** = 서비스 이용료(구간제) + 결제망 이용료 3.3% + 두 금액의 부가세 10%

| 판매 금액 구간 | 서비스 이용료 |
|---|---|
| 1원 ~ 70만 원 | 16.4% |
| 70만 ~ 200만 원 부분 | 9.4% |
| 200만 원 넘는 부분 | 4.4% |

카테고리에 따라 다를 수 있다고 적혀 있어요. 실제 값은 판매 관리 > 수익금 계산기로 확인해요.

**우리 가격대로 계산한 실수령액 (직접 계산)**

| 판매가 | 수수료 합계 | 실수령 | 실수령 비율 |
|---|---|---|---|
| 30만 원 | 65,010원 | 234,990원 | 78.3% |
| 50만 원 | 108,350원 | 391,650원 | 78.3% |
| 70만 원 | 151,690원 | 548,310원 | 78.3% |
| 100만 원 | 193,600원 | 806,400원 | 80.6% |

- **구매자도 따로 4.5%** 를 더 내요 (최소 900원 ~ 최대 13.5만 원). 판매가 30만 원이면 고객은 31.35만 원을 결제해요.
- 진행 순서: 주문 → 작업 → **'작업물 발송' 기능으로 전달** → 고객 구매 확정 (**응답 없으면 7일 뒤 자동 확정**) → 수익금 출금 신청.
- 세금계산서: 주문 금액은 **판매자가 직접 발행**해요 (사업자로 인증한 경우). 구매 수수료분은 크몽이 발행해요. 개인으로 인증하면 발행할 수 없어요. → 세금 관련은 별도 조사 (`service-guide.md` §9).

## 3. 금지 행위 — "데모 먼저" 전략과 부딪히는 부분

**금지 (2024-01 공지, 운영정책 2025-06-25판 기준)**
- 거래 확정 전 외부 연락처 공유, 외부 소통, 사전 미팅
- 크몽 밖에서 직접 결제 (계좌이체 유도 등)
- 서비스 설명·이미지·포트폴리오에 전화번호·이메일·SNS·**외부 링크**·QR 기재
- 적발되면 경고 없이 판매 중단되거나 **최대 365일 이용 제한**

**크몽 안에서 쓸 수 있는 것:** 크몽메시지, 0504 안심번호, 웹하드(500MB 넘는 파일)

**다른 판매자들은 어떻게 하나 (홈페이지 템플릿 서비스 20개 확인)**
- 상세페이지에 데모 주소를 공개한 곳은 **0개**예요.
- 대신 "주문하면 색·문구·사진을 바꾼 **시안 화면을 먼저 보내 드림**", "메인 시안 확인 후 진행"처럼 **주문 뒤 시안 단계**로 풀어요.

**우리 방식 제안 (확인 필요)**
1. 상세페이지·포트폴리오에는 템플릿 **스크린샷과 화면 녹화 이미지**를 넉넉히 넣어요 (외부 링크 없이).
2. 주문 뒤 첫 단계로 **고객 정보로 바꾼 메인 화면 시안**을 보내고, 확정하면 나머지를 진행해요.
3. 결제 전 크몽메시지로 데모 주소를 보내도 되는지는 **공식 문서에 없어요** → 크몽 1:1 문의로 확인해요. 허용되지 않으면 1·2번만으로 갑니다.

## 4. 서비스 설명에 쓰면 안 되는 표현

판매 이용약관 제8조와 표시·광고법을 근거로 크몽이 안내하는 체크리스트예요.
- **확인할 수 없는 최상급 표현**: 1위, NO.1, 최고, 최저, 최초, 유일, 베스트, 무한
- **보장 표현**: 100% 효과 보장, 상위노출 보장, 검색 1페이지 보장
- **증빙 없는 경력·학력·수상**: 쓰려면 프로필에 증빙을 등록하고, 못 하면 지워요
- **근거 없는 비교·비방**: "다른 업체는 호스팅에 묶어요" 같은 문장
- **불리한 조건 숨기기**: 수정 횟수·추가 비용·유지보수 범위를 빼먹으면 안 돼요
- **"뭐든 다 해 드려요"**: 직접 제공할 수 있는 범위만 적어요
- **다른 판매자 설명 복사**

→ 영향: `selling-points.md`의 차별화 문구를 이렇게 다듬어요.
- "디자이너가 직접 만든" → **사용자 경력 증빙을 등록하면** 쓸 수 있어요.
- "월 관리비 없음 · 100% 고객 소유" → 사실이라 쓸 수 있어요. 다른 업체와 비교하는 문장 없이 쓰기만 해요.
- SEO·AEO → "검색 구조 기본 적용"만 쓰고 순위 보장은 하지 않아요 (`seo-aeo-geo.md`와 같음).

## 5. 등록 심사 (비승인 자주 나는 이유)

**공통**
- 한 서비스에는 핵심 작업 하나만 넣어요. 성격이 다른 작업은 따로 등록해요.
- 경력·자격 표현에는 증빙이 필요해요.
- 외부 연락처를 쓰면 안 돼요.
- 과장·보장 표현은 고쳐야 해요.

**그 밖에**
- **템플릿 단순 판매**는 비승인될 수 있어요. 이 기준은 디자인 카테고리(캔바·미리캔버스 등)에 적힌 것이지만, 우리도 **"고객 정보로 바꿔 설치까지 해 줌"이라는 작업 범위**를 분명히 보여 줘야 해요.
- **포트폴리오**는 디자인 기준으로 실제 작업물 3건 이상이 필요해요. IT·프로그래밍 포트폴리오에는 기술을 1개 이상 등록해야 하고, 심사는 영업일 3~5일 걸려요. 1개 포트폴리오에는 1개 프로젝트만 넣어요. 비슷한 포트폴리오는 비승인되니 **템플릿마다 하나씩** 올리면 맞아요.
- 다른 판매자와 비슷한 설명·가격 구성은 비승인될 수 있어요 (창업·사업 카테고리 사례).
- 포트폴리오를 등록한 서비스는 평균 판매 금액이 4배라고 크몽이 안내해요 (크몽 자체 수치).

## 6. 취소 · 환불

- 작업 시작 전에는 취소·환불이 돼요.
- 작업 시작 후에는 **나눌 수 있는 작업이면 남은 부분만** 환불돼요. 나눌 수 없는 작업은 환불이 안 돼요.
- 구매 확정 후에는 크몽을 통한 환불이 안 되고 판매자와 직접 협의해요.
- 광고·계약 내용과 다르게 했으면 받은 날부터 3개월 또는 안 날부터 30일 안에 환불을 요청할 수 있어요.
- **판매자가 기본 규정보다 고객에게 유리한 조건을 적으면 그 조건이 먼저예요.** 그래서 "시안 확인 전 전액 환불"을 내걸 수 있어요.

→ 우리 제안: 단계를 **① 시안 전 → ② 시안 확정 → ③ 설치·납품**으로 나누고 단계별 환불 비율을 표로 공개해요 (가분 작업으로 만들기).

## 7. 신규 판매자 노출 · 등급

**검색 노출 순서는 공식 공개가 없어요.** 크몽은 "판매 데이터가 등급과 노출에 영향을 준다"고만 안내해요.

**등급 (매월 1일 갱신)**
- 처음에는 **NEW** 등급이에요.
- LEVEL 1이 되려면:
  - 누적 판매 1건 이상
  - 활동 30일 이상
  - 만족도 4.7 이상
  - 메시지 응답률 90% 이상 (첫 문의에 24시간 안에 답하는지로 계산)
  - 주문 성공률 85% 이상 (취소 제외 비율, 최근 2개월)
  - 작업일 준수율 85% 이상 (발송 예정일 안에 '작업물 발송')

→ 할 일:
- 문의 알림을 켜고 자동응답 문구를 준비해요.
- 일이 밀리면 **휴가 모드**로 주문을 막아요 (취소가 생기면 주문 성공률이 깎여요).
- 작업 기간은 넉넉하게 잡고, 늦어지면 '작업일 연장 요청' 기능을 써요.
- 허위 거래·리뷰 조작은 금지예요 (지인 주문으로 첫 리뷰 만들기 금지).

## 8. 남은 확인

- [ ] 결제 전 크몽메시지로 데모 사이트 주소를 보내도 되는지 (크몽 1:1 문의)
- [ ] 홈페이지 제작 카테고리(IT·프로그래밍)에서 "템플릿 기반"이라고 밝혀도 승인되는지
- [ ] 사용자 디자인 경력 증빙으로 무엇을 낼 수 있는지 (재직증명서·포트폴리오 등)
- [ ] 개인/사업자 판매자 선택과 매출 신고 → 세금 조사 때 (공지: "매출 신고는 어떻게 하나요? 2026.01부터 적용")
