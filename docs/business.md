## 확정

- 납품물: 카페24 WordPress에 올리는 Classic 테마 ZIP + 초기 설정
- 호스팅: 카페24 WordPress, **고객 명의**
- 방식: 템플릿 몇 종 중 고객이 고르고 → 고객 정보로 바꿔서 납품 (맞춤 제작은 기본 아님)
- 제외 업종: 병원·의원

| 항목 | 메모 |
|------|------|
| 템플릿 몇 종, 어떤 업종 | 예: 소규모 회사 소개 / 카페·매장 / 개인 브랜드·포트폴리오 … |
| 템플릿당 페이지 구성 | 메인 + 소개 + 서비스 + 소식 + 문의 정도? |
| 패키지 단계 | 예: 기본(템플릿 그대로) / 표준(+페이지·색 조정) / 프리미엄(+섹션 추가) |
| 가격 | 패키지별 |
| 수정 횟수 · 작업 기간 | |
| 고객이 관리자에서 고칠 수 있는 범위 | 소식/공지만? 메인 문구·이미지도? |
| 카페24 세팅 대행 여부 | 고객 계정 접속 방식 (비밀번호 직접 받지 않는 방법 검토) |
