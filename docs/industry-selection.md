# 업종 선정 조사

> 조사일: 2026-11-02
> 데이터:
> - 크몽 "홈페이지 신규 제작" 서비스 **1,195개** 제목 (공급 = 경쟁)
> - 리뷰 많은 상위 30개 서비스의 리뷰 **5,430개** (수요 = 실제 주문, 업종 밝힌 2,130개)
> - 업종 키워드별 검색 결과 상위 40개
> - 업종 특성(홈페이지 필요도·필요 기능·규제)은 웹 자료 + 판단

---

## 1. 수요: 실제로 누가 주문하나 (리뷰 업종)

|---|---|---|---|---|

- 제조업과 요식업은 **주문 금액이 높아요**(54만~59만). 제조는 기업 고객 비율이 53%예요.

## 3. 업종 특성 (우리 상품과 맞는지)

우리 상품은 소개형 홈페이지예요. 예약·결제·회원 기능은 없고, 고객이 직접 글을 고치는 구조예요.

| 업종 | 홈페이지가 필요한 이유 | 필요 기능 | 우리 구조와 맞음 | 주의 |
|---|---|---|---|---|
| **소규모 기업·제조·B2B** | 거래처가 신뢰 확인용으로 봄. 플레이스·인스타로는 대체 불가 | 회사 소개, 제품, 연혁, 인증서, 문의 | ◎ | 경쟁 많음 |
| **학원·교육** | 학부모가 강사·커리큘럼·공지를 확인함 | 강좌 안내, 강사, 공지(게시글), 상담 문의 | ◎ (공지 = 게시글) | 학원법: 교습비 거짓 표시 금지, 과대·거짓 광고는 행정처분 사유 |
| **인테리어·시공** | 시공 사례가 곧 영업 자료 | 시공 사례 갤러리(게시글), 견적 문의 | ◎ (사례 = 게시글) | 수요 크기를 확인 못 함 (리뷰 업종 분류에 없음) |
| **전문직 (세무·노무·법무·행정사)** | 신뢰가 곧 매출 | 전문가 소개, 업무 분야, 칼럼(게시글), 상담 문의 | ◎ | 직종별 광고 규정이 있음 (변호사 광고 규정 등 확인 필요) · 수요 작음 |
| 헬스·필라테스·요가 | 플레이스·인스타가 먼저고 홈페이지는 보조 | 프로그램, 강사, 시간표, 예약은 네이버 예약 링크 | ○ | 홈페이지 필요도를 설득해야 함 |
| 뷰티 (미용·네일·피부관리) | 같음 | 메뉴·가격, 갤러리, 예약 링크 | ○ | "치료·개선" 같은 의료 효과 표현은 의료법 위험 |
| 요식·카페 | 플레이스가 거의 다 함. **프랜차이즈 가맹 모집**일 때만 홈페이지가 필요 | 브랜드, 메뉴, 가맹 안내, 문의 | △ (가맹 모집형만 ○) | |
| 펜션·숙박 | 예약이 핵심 | 실시간 예약 | ✕ (예약 엔진 필요) | 지금 범위 밖 |
| 부동산 분양 | 한 번 쓰는 랜딩 | 분양 정보, 상담 신청 | △ | 저가·당일 경쟁, 표시광고 규정 |
| 병의원 | | | ✕ | 의료광고 규제로 제외 (확정) |

## 4. 제안: 첫 템플릿 업종 (결정은 사용자가)

시장조사 §8에 따르면, 상위 판매자는 **하위 페이지 구조는 같게 두고 메인 페이지만 업종별로** 바꿔요. 그래서 업종을 늘리는 비용은 "메인 디자인 + 샘플 문구·사진" 정도예요.

| 순서 | 템플릿 | 근거 |
|---|---|---|
| 1 | **소규모 기업·제조 소개형** | 수요가 가장 크고 기업 고객이라 단가가 높음(54만). 모든 업종의 바탕이 됨 |
| 2 | **학원·교육형** | 구체 업종 수요 1위(7.9%), 재구매 42%인데 특화 판매자가 거의 없음 |
| 3 | **인테리어·시공 사례형** 또는 **전문직형** | 경쟁이 거의 없고, 게시글 구조(사례·칼럼)가 블록 테마의 직접 수정과 잘 맞음 |
| 이후 | 헬스·필라테스 / 뷰티 (예약 링크형) | 공급은 비어 있지만 홈페이지 필요도를 설득하는 비용이 듦 |
| 안 함 (초기) | 펜션·쇼핑몰·병의원·분양 | 예약·결제가 필요하거나 규제·저가 경쟁 |

- 템플릿 이름(slug)과 최종 업종은 사용자 확인 후 `decisions.md`에 적어요.
- 확인이 덜 된 것:
  - 인테리어·전문직 수요는 리뷰 업종 분류에 따로 없어서 크기를 못 쟀어요.
  - 직종별 광고 규정(변호사·세무사·공인중개사)은 법령 원문을 확인해야 해요.
