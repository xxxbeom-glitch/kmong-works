# 크몽 고객 리뷰 분석

> 조사일: 2026-11-02 · 대상: "홈페이지 신규 제작" 리뷰 많은 상위 25개 서비스의 최근 리뷰 (서비스당 최대 300개)
> 총 **4,962개** 리뷰 · 리뷰에 붙은 실제 주문 금액·작업일·재구매 여부·고객 업종 포함

## 3. 고객이 화내는 것 (별점 4.5 미만 80개 분석)

| 불만 | 내용 (요약) | 우리 대응 |
|---|---|---|
| **연락 두절·지연** (가장 많음) | 수정 요청 후 몇 주 잠수, 예정일 지나서 초안, 크몽에 신고해야 답이 옴 | 응답 시간 약속 + 작업일 짧게 + 진행 상황 먼저 알리기 |
| **숨겨진 조건** | 1차 납품 후 "자기 호스팅 써야 한다", 설명에 잘 안 보이게 써 둠, 다른 곳 이전 거부 | 고객 명의 카페24 + 이전 자유를 **첫 화면에** 명시 |
| **플랫폼 종료 미고지** | 쓰던 웹빌더 서비스가 곧 종료되는데 말 안 해 줌 → 환불 거절 | 워드프레스(오픈소스)라 종료 위험 없음을 장점으로 |
| **추가금 요구** | 수정 요청마다 추가금, 추가 결제 강요 | 수정/추가 작업 기준을 미리 표로 공개 |
| **데이터 안 넘겨줌** | 관리자 계정·데이터 미이전, 연락처 바뀜 | 고객 명의 계정에 처음부터 설치 → 넘길 것 자체가 없음 |
| **판매자 독단·태도** | 상의 없이 디자인 갈아엎음, 수정 거부, 모욕·협박성 발언 | 템플릿을 먼저 보고 고르므로 "기대 불일치"가 적음 + 정중한 응대 원칙 |
| **담당자 변경·반복 설명** | 중간에 담당자가 바뀌어 같은 말 반복 | 1인 작업이라 해당 없음 (장점) |
| **디자인 감각 부족** | 무난하지만 차별화·브랜드 감각 부족 (고가 주문) | 디자이너가 만든 템플릿 품질로 승부 |
| **초보에게 어려운 안내** | 홈페이지를 모르는 사람에겐 과정 설명이 어려움 | 쉬운 말 안내서 + 영상 |
| **워드프레스 적응** | 템플릿형(워드프레스)은 처음이면 적응 노력 필요 (4점) | 영상 매뉴얼 + 첫 주 질문 빠른 응답 |

→ 불만의 대부분은 **실력이 아니라 "연락"과 "숨긴 조건"**. 1인 판매자가 가장 지키기 쉬운 부분.
→ 리뷰 중 별점은 낮은데 글은 칭찬인 경우도 있음 (고객 실수) — 별점 자체에 너무 신경 쓸 필요 없음.

## 4. 템플릿 판매자 리뷰 (우리와 같은 방식)

### 십분의일 (리뷰 300개 분석, "템플릿 복사 + 영상 매뉴얼, 수정은 고객이")

- **작업일 64%가 "24시간 이내"** — 결제하면 바로 복사해 주고 끝.
- 주문 85%가 20만 원 이상(본상품 33만), 13%가 10만 원 미만(추가 요청).
- 재구매 37% — **템플릿을 하나 더 사는 고객**이 있음 (대행사·여러 사업체 운영자).
- 고객이 좋아한 점 (요약):
  - 영상 매뉴얼·유튜브 따라 하니 처음인데도 직접 만들었다
  - **"외주 맡기면 어차피 글은 내가 써야 하고 수정이 오가느라 오래 걸린다 → 혼자 고치는 게 더 편하다"**
  - 오탈자 하나 고칠 때도 업체에 요청할 필요가 없어서 좋다
  - 200~300만 원 견적 보다가 이 가격에 이 품질이라 만족
  - 막히면 채팅으로 1시간 안에 답이 와서 혼자서도 끝낼 수 있었다
  - 나이 많은 고객도 단계별로 가르쳐 줘서 해냈다
- 아쉬운 점: 워드프레스를 처음 쓰면 적응 노력이 필요하다는 의견 (4점).

### 파라드림 (리뷰 195개, "템플릿 복사 + 맞춤 수정 대행")

- 주로 22만 원, 작업일 1~5일.
- 재구매 40% — 같은 고객이 템플릿을 또 사거나 작은 수정(3만·6만)을 반복 결제.
- 고객이 좋아한 점 (요약):
  - **"템플릿형이라 내가 잘할 수 있을지 걱정했는데"** 설명서가 쉬워서 해냈다
  - 크몽이 처음이라 불안했는데 답이 바로바로 와서 안심
  - 포트폴리오(데모) 퀄리티를 보고 샀고 그대로 나왔다
  - 템플릿 홈페이지 중 가장 저렴

### 두 곳의 공통점

1. 고객 대부분이 **홈페이지 초보**이고, 처음엔 **불안**해함.
2. 불안을 없앤 건 **쉬운 매뉴얼 + 빠른 답장**.
3. "직접 고칠 수 있다"는 게 실제로 **만족 이유**로 언급됨 (마케팅 문구가 아니라 진짜 장점).
4. 데모를 보고 사니 결과물 불만이 거의 없음.

## 5. 우리한테 의미하는 것

1. **가장 큰 무기는 "응답 속도"와 "투명함".** 경쟁자의 1점 리뷰는 거의 다 연락 두절·숨긴 조건. 반대로 하면 이긴다.
   - 상품 페이지에 응답 시간 약속 (예: 평일 N시간 내)
   - 고객 부담 비용·수정 기준·소유권을 첫 화면에
2. **매뉴얼 품질이 곧 상품 품질.** 템플릿형 리뷰의 칭찬 1순위가 매뉴얼. 영상 + 쉬운 글 + 초보 기준으로.
3. **템플릿 + 직접 수정은 고객에게도 진짜 장점**으로 받아들여짐 ("외주보다 편하다"). 숨길 이유 없음.
4. **작업일을 짧게.** "빠름"이 칭찬 1위. 템플릿 방식이면 1~3일 가능.
5. **추가 결제로 이어지는 구조가 자연스러움** — 작은 수정 3만·6만 원이 반복 결제되고, 템플릿을 하나 더 사는 고객도 있음.
6. **대행사·여러 사업체 운영자**는 재구매 고객 후보 → 나중에 "2개 이상 구매 할인" 같은 옵션 고려.
7. 워드프레스 적응 문제 → 블록 편집기 매뉴얼을 특히 쉽게, 첫 주 집중 지원.
