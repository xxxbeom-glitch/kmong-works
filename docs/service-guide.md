# 서비스 운영 가이드 (주문 → 납품 → 사후)

> 처음 수주 판매를 하는 기준으로 정리. 금액 중 **"시장"** 표시는 크몽 상위 판매자 상세페이지에서 확인한 값(2026-11-02), **"제안"** 표시는 아직 정하지 않은 우리 안.
> 정해지면 `decisions.md`에 기록하고 크몽 상품 페이지 문구로 옮긴다.

---

## 1. 전체 흐름 한눈에

```
[판매 전·1회]  템플릿 데모 사이트 · 매뉴얼 · 안내 문서 준비
      ↓
① 상담(크몽 메시지)  → 템플릿·패키지 확정
② 결제(크몽)
③ 자료 받기          → 작업일은 "자료가 다 온 날"부터 계산
④ 호스팅·도메인 준비 → 고객 명의 카페24
⑤ 제작               → 템플릿 설치 + 고객 내용으로 교체
⑥ 1차 확인 → 수정    → 정해진 횟수만큼
⑦ 오픈               → 도메인 연결 · 최종 점검
⑧ 납품               → 크몽에 완료 처리 + 매뉴얼 전달
⑨ 구매 확정
⑩ 사후               → 무상 오류 수정 기간 → 이후 유료 / 월 관리
```

## 3. 기본 포함 vs 추가 비용

### 기본 포함 (제안)

- 템플릿 1종 설치 + 공통 서브페이지 (회사소개 · 서비스 · 공지 · 문의 등 — 패키지에 따라 페이지 수)
- 로고 · 대표색 · 상호 · 연락처 · 주소 · SNS · 문구 · 사진 교체
- 문의폼 (메일 알림) · 공지 게시판 · 지도(오시는 길)
- PC · 태블릿 · 모바일 대응
- 도메인 연결 + SSL + 검색엔진 기본 등록
- 수정 N회 (시장 중앙: 기본 2회 · 중간 3회 · 고급 5회)
- 사용법 영상 매뉴얼
- 오픈 후 **무상 오류 수정 기간** (시장: 1~3개월. 제안: 1개월 — 내가 만든 것에서 생긴 오류만)

### 추가 비용 항목 (시장 금액)

| 항목 | 시장 금액 | 메모 |
|---|---|---|
| 추가 수정 (횟수 초과 / 납품 후) | 건당 **5천 ~ 3만 원** (1만·2만·3만이 흔함) | "단순 교체 기준"으로 선 긋기 |
| 서브페이지 추가 | 1만 원부터 (저가) ~ 페이지 수로 패키지 상향 | 공통 페이지가 있어 실제 일은 적음 |
| 섹션 추가 | 1만 원부터 | 부품(패턴) 재사용 |
| 도메인 구매·연결 대행 | 5만 원부터 | 고객 대신 처리할 때 |
| 문구 작성 · 이미지 제작 | 이미지 5천 원부터 | AI 활용 가능 |
| 월 관리 (업데이트·백업·장애 대응) | **월 3만 원부터** | 선택 상품 |
| 관리자 기능·특수 기능 (예약, 회원 등) | 별도 견적 | 기본 상품에선 제외 권장 |
| 빠른 작업 | 크몽 "빠른 작업" 옵션 | |

### 하지 않는 것 / 책임지지 않는 것 (상세페이지에 명시)

- 회원가입 · 결제 · 쇼핑몰 · 예약 시스템 (기본 상품 제외)
- 검색 순위 보장 · 광고 대행
- 고객 제공 사진·글의 저작권과 내용(광고 표현 등)에 대한 책임
- 카페24 장애, 호스팅·도메인 만료로 인한 접속 불가
- 고객이 직접 수정하다 깨진 화면 → 유료 복구 (월 관리 고객은 포함)
- 디자인 방향 전면 변경 · 템플릿 변경 → 재작업 비용

## 4. 호스팅 · 도메인 처리

### 원칙

- **호스팅·도메인은 고객 명의, 고객이 카페24에 직접 결제.** 소유권이 고객에게 있어야 나중에 분쟁이 없고 "100% 고객 소유"로 팔 수 있다.
- **크몽 밖에서 돈을 받지 않는다.** 호스팅비를 내가 대신 받아 결제하는 식은 피하고, 추가 작업비도 크몽 안에서 추가 결제로 받는다. (크몽은 외부 직거래를 금지 — 정확한 규정은 판매자 센터에서 확인)

### 비용 (고객 부담, 시장 안내 금액 — 실제는 카페24에서 확인)

| 항목 | 금액 |
|---|---|
| 도메인 (.com / .co.kr) | 연 1~3만 원 |
| 카페24 호스팅 | 월 1,350 ~ 6,300원대 (판매자 상세페이지 기준, 워드프레스 호스팅 요금은 별도 확인) |
| SSL | 카페24 무료 SSL |

→ 상세페이지에 "제작비 외 고객 부담: 도메인·호스팅 연 몇만 원"을 **반드시 미리** 적는다. (상위 판매자 70%가 명시)

### 접속 정보 받는 법 (비밀번호 최소화)

1. **고객이 직접:** 카페24 가입 → 워드프레스 호스팅 신청 → 도메인 구매. (단계별 안내 문서·영상 제공)
2. 고객이 워드프레스 관리자에 **내 계정을 하나 만들어 준다** → 테마 설치·제작은 이걸로 충분.
3. 도메인 연결처럼 카페24 계정이 필요한 단계만:
   - 고객이 안내 보고 직접 하거나
   - 임시로 접속 정보를 받고 → **납품 때 비밀번호 변경 안내**
4. 받은 접속 정보는 이 저장소에 절대 커밋하지 않는다. (`clients/*/_private/`도 git 제외지만 비밀번호는 아예 파일로 남기지 않는 걸 원칙으로)
5. 납품 후 내 워드프레스 계정은 삭제하거나, 월 관리 고객이면 유지.

### 고객이 이미 호스팅·도메인이 있으면

- 카페24 워드프레스면 그대로 진행.
- 다른 회사 호스팅이면 → 카페24로 새로 만들기를 권장하거나 별도 견적. (기본 상품은 카페24 기준)
- 도메인만 다른 회사면 → 연결 설정만 하면 됨 (네임서버/DNS 변경 안내).

## 5. 준비물

### 내가 판매 전에 준비할 것 (1회)

- [ ] 템플릿 데모 사이트 (내 카페24, 템플릿마다 1개)
- [ ] 데모 이미지는 **무료 라이선스**만 (고객 사이트에 그대로 남을 수 있음)
- [ ] 고객용 매뉴얼: 영상 3~5개 (글 수정 · 사진 교체 · 공지 쓰기 · 메뉴 수정 · 문의 확인)
- [ ] 카페24 가입·호스팅 신청·도메인 구매 안내 문서 (캡처 포함)
- [ ] 자료 요청 양식 (아래 "고객 준비물" 그대로)
- [ ] 개인정보처리방침 기본 양식
- [ ] 납품 안내문 (접속 주소 · 관리자 주소 · 매뉴얼 링크 · 비밀번호 변경 안내 · 무상 지원 기간 · 문의 방법)
- [ ] 크몽 상품 페이지 (포함 범위 · 추가 비용 · 고객 부담 비용 · 수정 기준 · 환불 기준 · 작업 절차 · FAQ)
- [ ] 결정: 사업자 등록 / 세금계산서 발행 여부 (크몽 판매자 56%가 세금계산서 가능 표시)

### 고객이 준비할 것 (자료 요청 양식)

- [ ] 고른 템플릿 번호
- [ ] 상호 / 브랜드명
- [ ] 로고 파일 (없으면 텍스트 로고로)
- [ ] 대표색 (없으면 로고에서 추출)
- [ ] 연락처 · 이메일 · 주소 · 영업시간 · SNS 링크
- [ ] 사업자 정보 (상호 · 대표자 · 사업자번호 — 하단 표시용)
- [ ] 페이지별 문구 (회사소개 · 서비스 설명 등 — 없으면 키워드만)
- [ ] 사진 (매장 · 제품 · 대표 · 작업 사례)
- [ ] 문의 받을 이메일
- [ ] 원하는 도메인 주소 (후보 2~3개)
- [ ] 카페24 가입 + 워드프레스 호스팅 신청 + 도메인 구매 완료 (안내 문서 보고)
- [ ] 워드프레스 관리자 계정 (내 계정 생성 또는 임시 공유)

→ **작업일은 위 자료가 다 들어온 날부터** 센다고 상세페이지에 명시. (시장 공통)

## 6. 수정 기준 (상세페이지 문구용)

**수정 (횟수 차감):** 오탈자 · 문구 일부 변경 · 사진 교체 · 색 미세 조정 · 메뉴명 변경 · 연락처/링크 변경 · 간단한 배치 조정
**추가 작업 (별도 비용):** 신규 페이지/섹션 · 새 기능 · 디자인 방향 전체 변경 · 템플릿 교체 · 메뉴 구조 전체 변경
**무상 (횟수 차감 없음):** 내가 만든 부분의 오류·깨짐

- 수정 요청은 **모아서 한 번에** 받으면 1회로 계산 (시장 관행: "요청을 모아 반영하는 묶음")

## 7. 취소 · 환불

- 기본은 **크몽 기본 규정** (작업 시작 전 전액 / 시작 후 진행분 제외 등).
- 템플릿 상품 특징: 설치·커스텀 시작 전이면 전액 환불 쉬움. 경쟁자는 "7일 내 100% 환불(커스텀 시작 전)"로 신뢰를 삼.
- **고객 부담 호스팅·도메인 비용은 환불 대상 아님**을 미리 안내 (카페24에 직접 낸 돈).

## 8. 사후

| 기간 | 내용 |
|---|---|
| 오픈 후 1개월 (제안) | 내가 만든 부분 오류 무상 수정 |
| 이후 | 추가 수정 건당 유료 · 또는 월 관리 상품 |
| 월 관리 (선택, 시장 월 3만 원~) | 워드프레스·플러그인 업데이트 · 백업 확인 · 깨짐 복구 · 간단 수정 월 N건 |

- 고객에게 남기는 안내: 업데이트 주기, 백업 방법, 호스팅·도메인 만료일 확인 (카페24에서 알림 옴).
- 시장의 무료 기간·월 관리 가격·마케팅 문구는 `maintenance-research.md` (1년 18곳 · 1개월 15곳, 월 관리 3만~5만 원 중심).
