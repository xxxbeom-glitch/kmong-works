## 5. 판매 정책 패턴

1. **도메인·호스팅·SSL은 별도** — 대부분 금액까지 안내 (도메인 연 2만 원대, 서버 월 1천~1만 원대).
2. **수정 범위 정의** — "오탈자·문구·이미지 교체는 수정 / 신규 페이지·기능·디자인 방향 변경은 추가 비용" 식으로 선을 긋는다.
3. **결제 전 상담 유도** — "커스텀 특성상 결제 전 문의 필수". 시작가는 낮게, 실제 금액은 상담에서.
4. **자료 준비 체크리스트** — 상호·메뉴·문구·로고/사진·참고 사이트·기능·도메인 정보.
5. **환불은 크몽 기본 규정** 그대로가 다수. 소수는 "7일 내 100% 환불" 같은 강한 보장으로 차별화.
6. **유지보수** — 1개월 무료 제공 또는 월정액 별도.

## 6. 우리한테 의미하는 것

- **템플릿 기반이라고 숨길 필요 없음.** 리뷰 449개·195개·274개 판매자가 템플릿 번호·템플릿 브랜드·"템플릿 vs 주문제작" FAQ를 대놓고 쓴다. 고객은 "샘플 보고 고르는 것"을 오히려 편하게 여김.
  반대로 "100% 맞춤 신규 디자인"이라고 해놓고 재사용 디자인을 주면, 크몽 규정상 **"표시·광고 내용과 다른 용역"은 3개월 내 환불 대상**이라 분쟁 위험이 있다. → 추천 표현: **"검증된 디자인 템플릿 + 우리 회사에 맞게 커스터마이징"**.
- **가격 시작점:** STANDARD 25~35만 / DELUXE 55~70만 / PREMIUM 110~130만 (시장 중앙과 같은 선). 템플릿이라 작업 시간이 짧으니 이 가격대에서 마진이 남는 구조.
- **작업일:** 템플릿 강점 = 속도. STANDARD 3~5일이면 상위권 수준.
- **차별화 포인트 후보:** 고객 명의 카페24 WP(소유권·이전 자유) · 관리자에서 직접 수정 · 디자이너가 만든 템플릿 품질 · 빠른 납품.
- **경쟁:** 리뷰 0개가 44%. 첫 리뷰 확보가 가장 큰 벽 → 초기엔 가격보다 포트폴리오(템플릿 데모 사이트)와 리뷰 확보 전략이 중요.

### 템플릿 구성 방식

- **하위 페이지(메뉴)는 10개 템플릿 전부 동일**, 메인 페이지만 업종별로 다르게.
  - 십분의일 공통 메뉴: 회사소개(인사말·연혁·오시는 길) / 사업분야(디자인 1·2) / 제품소개 / 고객지원(공지사항·뉴스·FAQ·문의하기) + "3초만에 문의하기" 버튼
  - 파라드림 공통 메뉴: 회사소개 / 서비스 소개(A·B) / 작업사례 / 고객지원(공지·블로그·FAQ·문의)
- 업종 분포 (십분의일 10종): 비즈니스 4 · 마케팅 2 · 테크 1 · 크리에이티브 1 · 레스토랑 1 · 식품 1. 파라드림은 일반기업·바이오 등.
- 메인 길이 PC 기준 5,000~9,000px, 섹션 7~10개. 흐름: 히어로 → 소개 → 서비스/강점 → 숫자·실적 → 사례/후기 → 뉴스 → FAQ → 문의 CTA.
- 데모 하나(9번)를 **자기 영업 페이지**로 씀: "실제 300만 원에 제작된 홈페이지를 30만 원에", "350곳이 넘는 업체가 사용", "가장 많이 팔린 7번 템플릿" 같은 판매 순위 표시.

### 우리 계획과 부딪히는 점

- 기존 결정은 "Classic 커스텀 테마 · 섹션 문구는 코드 고정 · 빌더는 요청 시만". 그런데 상위 판매자들의 팔리는 이유는 **"고객이 직접 다 고친다"**이고, 그걸 Elementor가 해결하고 있음.
- 선택지:
  1. **Elementor Pro 기반 템플릿** — 시장에서 증명된 방식, 복제·납품이 빠름. 단점: 디자인이 비슷해지기 쉬움, 무거움, Elementor Pro 라이선스 비용(사이트 수 기준 요금제) 고려 필요.
  2. **Classic 테마 + 관리자 입력칸(ACF 등)** — 가볍고 디자인 통제가 쉬움. 단점: 고객이 고칠 수 있는 범위가 정해진 칸으로 제한됨 → "다 고칠 수 있다"는 경쟁 포인트에서 약함.
  3. **블록 테마(구텐베르크) + 패턴** — 워드프레스 기본 기능만으로 편집 가능, 라이선스 비용 없음. 단점: Elementor보다 편집 화면이 낯설 수 있음.
- **결정 (2026-11-02): 3번 블록 테마.** Elementor Pro는 쓰지 않음 → `decisions.md`
