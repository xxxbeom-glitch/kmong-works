### "1년 무료"의 실제 조건 (예시 요약)

- **자기 호스팅을 쓸 때만** 1년 무상 — 사실상 호스팅에 묶는 장치 (리뷰 27, 견적에 호스팅·SSL·1년 유지보수 포함)
- **템플릿형은 1년 무료, 맞춤형은 1개월** — 템플릿은 고칠 게 적어서 길게 줘도 부담이 적음 (리뷰 141)
- 1년 무료 범위가 **"호스팅 이전·도메인 연장·SSL 설치" 같은 기본 관리**뿐인 경우 (리뷰 78)
- **텍스트 1~2줄·이미지 교체만** 1년 무료, 기능 추가·대규모 수정은 별도 (리뷰 49)
- "자사 오류(버그)"만 무상, 고객 요청 변경은 아님 (리뷰 49, 24)
- 호스팅 3개월 무상 → 이후 **유지보수 계약으로 연장** (리뷰 142)

### 무료 기간 이후

- 건당 1만 원 (3개월 무료 후)
- 유지보수 계약 / 별도 문의 (대부분)
- "필요한 달에만 신청" (리뷰 69)

## 3. 유료 유지보수 가격 (공개한 곳)

| 형태 | 가격 | 내용 |
|---|---|---|
| 월 관리 | **월 3만 원~** | 버그 수정·간단 콘텐츠 업데이트·보안 패치 / 기본 운영 지원 |
| 월 관리 | **월 5만 원** | 호스팅 유지 + 기본 문의 대응 |
| 월 관리 | 월 10만 원 | 이슈 발생 시 빠른 대응 |
| 월 관리 (필수, 최소 3개월) | 월 12만 원 | 가동·SSL·백업 점검, 월 30분 이내 경미한 수정 |
| 월 관리 | 월 30만 원~ | 기능을 계속 늘리는 개발형 |
| 연간 | 연 13.2만 원 | 1년간 간단 수정·텍스트 변경 무제한 |
| 단기 옵션 | +5만 원 / 1개월 | 월 2회 문구·사진 수정 |
| 건당 | 1만 원 · 3만 원 | 무료 기간 이후 수정 건당 |
| 서버·관리비 | 월 5천 원 / 연 2.2만 원~ | 자체 호스팅 관리비 (사실상 호스팅비) |

→ **소상공인 대상 월 관리는 3만~5만 원이 중심.** 10만 원 이상은 빠른 대응·개발 포함형.

## 4. 마케팅 문구 유형

| 유형 | 예 (요약) | 노리는 불안 |
|---|---|---|
| **긴 무료 기간** | "1년 무상 유지보수", "만들고 나몰라라 하지 않습니다" | 오픈 후 잠수 |
| **관리비 없음** | "저에게 내는 월 관리비가 없습니다", "매달 내셔야 하는 이용료 없음", "유지보수 비용 폭탄? NO!" | 계속 나가는 돈 |
| **고객 명의** | "도메인·서버는 의뢰인 명의로 직접 구매, 제가 대신 사서 마진을 붙이지 않습니다" | 업체에 묶임 |
| **필요할 때만** | "이후 유지보수는 선택, 필요한 달만" | 강제 계약 |
| **역마케팅** | "'1년 무상 유지보수'를 내세우는 업체를 주의하세요" (고가 맞춤형) | 과장 약속 |

→ 리뷰 분석의 1점 원인(연락 두절·숨긴 조건·호스팅 묶기)과 정확히 같은 지점을 건드림.

## 5. 우리한테 의미하는 것

1. **"무료 유지보수"는 범위를 쪼개서 정의해야 안전하다.** 시장의 "1년 무료"는 대부분 조건이 붙어 있고, 우리가 무조건 1년을 약속하면 1인 작업에 부담.
   - 제안: **"내가 만든 부분의 오류(버그)는 {3개월~1년} 무상"** + **"글·사진 교체는 고객이 직접 (매뉴얼 제공)"** + 그 외는 건당/월 관리.
   - 블록 테마 + 고객 직접 수정 구조라 실제로 들어올 오류 요청은 적음 → **템플릿형은 긴 무료 기간을 줘도 부담이 적다** (리뷰 141 판매자와 같은 논리).
2. **"월 관리비 없음 · 고객 명의 · 이전 자유"가 이미 쓰이는 마케팅 문구**이고, 우리 구조와 그대로 맞는다. 숨길 조건이 없으니 그대로 써도 됨.
3. **월 관리 상품은 3만 원(기본)/5만 원(+간단 수정 N건)** 정도가 시장 중심. 업데이트·백업 확인·깨짐 복구·간단 수정.
4. 무료 기간 이후 **건당 가격**(1만~3만 원)을 미리 표로 공개 → "추가금 폭탄" 불안 해소.
5. 피할 것: 호스팅을 조건으로 건 무료 유지보수, "평생 무료" 같은 문구.

→ 결정은 `service-guide.md` §9 (무상 지원 기간 · 월 관리 상품).
